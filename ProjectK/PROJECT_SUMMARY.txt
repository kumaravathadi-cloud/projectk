To test chat interaction, you need:

  FROM AZURE PORTAL:
  1. Go to: portal.azure.com
  2. Find: Your OpenAI resource
  3. Go to: "Keys and Endpoint"
  4. Copy:  
     - Key 1                           → AZURE_OPENAI_API_KEY
     - Endpoint URL                    → AZURE_OPENAI_ENDPOINT
     - API Version (usually 2024...)   → AZURE_OPENAI_API_VERSION

  VERIFY DEPLOYMENT:
  - Deployment name must be: gpt-4o
  - Or edit: agent.yaml deployment_id to match your deployment

  PUT IN .env:
  $ AZURE_OPENAI_API_KEY=sk-xxxxx
  $ AZURE_OPENAI_ENDPOINT=https://your-resource.openai.azure.com/
  $ AZURE_OPENAI_API_VERSION=2024-08-01-preview
